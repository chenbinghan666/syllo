# VCI component provenance

User-selected source: https://vibecodecomponents.com/ (public pages inspected 2026-11-14).

VCI provides component prompts. This app adapts the public patterns into vanilla JavaScript and Shadow DOM; no premium/locked prompts were accessed, and no installable VCI package is claimed.

| App surface | Public reference | Adaptation |
|---|---|---|
| Left module rail | https://vibecodecomponents.com/navigation-components#slide-in-menu | Persistent labeled rail, badge, hover feedback and bottom action |
| Header path | https://vibecodecomponents.com/navigation-components#breadcrumbs | Compact current-section breadcrumb |
| Home entries | https://vibecodecomponents.com/content-components#card-grid | Tinted icon cards with count, hover and direct destination |
| Task rows | https://vibecodecomponents.com/#draggable-cards | List hierarchy and star control; personal pin replaces drag/archive |
| Filters | https://vibecodecomponents.com/#tabs | Grouped, selected-state segmented filters |
| Details | https://vibecodecomponents.com/#slide-over-panel | Right sheet, title, metadata, source action and dismissal |
| Feedback | https://vibecodecomponents.com/#toast-notifications | Status icon, message, close and timed dismissal |
| Theme action | https://vibecodecomponents.com/#toggle-switches | Reversible warm light/dark theme |

Observed VCI typography/icon choices: Outfit and Lucide. The user's no-blue requirement overrides reference colors: warm white, charcoal, terracotta, sage and peach form the app palette. Existing Moodle-specific calendar, grade values and sync logic are retained within the shared visual system.
