# Visual assets

Active icons: Lucide, https://github.com/lucide-icons/lucide. Embedded SVG paths in visuals.js. ISC license: LUCIDE-LICENSE.txt.

Active Latin/numeric font: Outfit 400/500/600/700, bundled locally as vci-outfit*.ttf. SIL Open Font License: OUTFIT-OFL.txt.

Chinese: Source Han Sans SC variable WOFF2 from the official Adobe release branch, bundled as source-han-sans-sc.woff2 (SOURCE-HAN-SANS-LICENSE.txt). Full font coverage avoids character-by-character fallback for course content. Legacy Noto subsets remain unused assets.

Earlier Inter/Manrope subsets and Phosphor SVG files remain legacy development assets with their licenses; they are not the active visual system. Fonts load locally without external runtime font requests. These assets imply no affiliation with VCI, the school or their authors.

Syllo SVG marks: outlined Outfit glyphs. Site emblems are discovered at runtime; no school-specific emblem asset is bundled.

Moodle logo: unmodified pix/moodlelogo.svg from the official moodle/moodle MOODLE_405_STABLE repository. Its inclusion identifies the underlying Moodle service; Syllo is independent. Upstream license: MOODLE-GPL.txt.

Active Syllo symbol: syllo-logo.png, generated for this project with the built-in image generation tool. Design source and prompt: branding-v1/README.md. Used beside the existing outlined Outfit wordmark and as the page favicon.
