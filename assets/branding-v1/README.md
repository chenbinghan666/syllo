# Syllo — 学习有径

本次设计为独立的新 Logo 提案。现有应用标识暂未替换。

## 设计意图

以 Syllo 首字母 S 为主轮廓，用相互衔接的折页表现课程、作业、课件与成绩汇集到同一学习入口。折页之间的留白表现清晰的学习路径。图形首先应是易辨识的 S，书页与路径是第二层含义。

橙色延续现有界面的 #F98012，深橙 #C65A13 用于折面。主张使用少量平面色和简洁轮廓，以便后续制作单色印刷及小尺寸图标。

## 交付与边界

- `syllo-logo-concept.png`：内置 image_gen 生成的透明背景标识提案。
- 当前交付为栅格设计稿，不是矢量母版；小尺寸识别与透明度须以实际输出检查为准。
- 实际生成稿带有轻微明暗过渡，未完全遵循纯平面色要求；正式矢量化时应简化为两种纯色。已检查 PNG 为 RGBA 透明背景。
- Syllo 是独立客户端，本标识不表示 Moodle 或学校官方背书。
