# Syllo

Syllo 是一个个人 Moodle 桌面学习客户端。它把课程、作业、通知、课件、成绩和日程整理到同一个窗口里。Syllo 不是学校官方产品，也不会自动提交作业、参加测验或修改成绩。

当前发布版：Windows 10 / 11（64 位）。

## 安装

推荐双击 `Syllo-Setup-v0.8.0.exe`：

1. 选择安装位置，然后点击“安装”。
2. 安装程序会创建桌面和开始菜单快捷方式，不需要管理员权限。
3. 安装完成后直接启动 Syllo。

如果不希望安装，也可以解压 `Syllo-Windows-x64-v0.8.0.zip`，进入解压后的 `Syllo` 文件夹，双击 `Syllo.exe`。便携版必须保留整个文件夹，不能只单独复制 `Syllo.exe`。

## 第一次使用

1. 输入学校 Moodle 根网址。XMUM 使用 `https://l.xmu.edu.my`。
2. 在学校自己的登录窗口中完成登录。
3. 登录成功后，Syllo 会读取当前账号可访问的课程与学习内容。
4. 勾选“在这台电脑上记住登录”后，授权信息会使用 Windows 本机加密保存；不勾选时，退出连接会删除本机授权。

不同学校是否可用取决于其 Moodle 是否开放官方移动端接口，以及是否启用所需插件。当前完整验证环境是 XMUM；其他学校可能只能读取部分内容。

## 安全和隐私

- Moodle 密码只在学校登录页面输入，Syllo 不保存密码。
- Syllo 只调用预设的只读接口，不会自动提交作业、参加测验或修改成绩。
- 学习数据缓存保存在 `%APPDATA%\Syllo`，不会写入便携版文件夹。
- 分享应用时不要分享 `%APPDATA%\Syllo`，其中可能包含你的本机加密授权和学习缓存。

## 常见问题

**Windows 显示“已保护你的电脑”**

当前安装包未购买代码签名证书，因此 Windows SmartScreen 可能显示未知发布者。请先确认文件来自可信来源，并用 `SHA256SUMS.txt` 核对安装包或 ZIP 的 SHA-256，再选择“更多信息 → 仍要运行”。

**连接失败**

检查网址是否为学校 Moodle 根网址、网络是否可用，以及学校是否启用了 Moodle 移动端服务。学校登录窗口关闭后需要重新点击连接。

**内容没有立即更新**

点击界面右上角的刷新按钮。启动时会优先显示最近一次加密缓存，再按需要更新；课程结构和封面图片的缓存时间更长，强制刷新会绕过缓存。

**卸载**

安装版可在 Windows“设置 → 应用 → 已安装的应用”中卸载 Syllo，也可运行安装目录内的 `Uninstall.exe`。卸载不会自动删除 `%APPDATA%\Syllo`；如需彻底移除个人数据，请在退出 Syllo 后手动删除该文件夹。

## 文件说明

- `Syllo-Windows-x64-v0.8.0.zip`：便携版压缩包，解压后运行。
